# 虚构数据导入模板

这些 CSV 是字段模板与联调样例，**不是实际学校数据，也不表示已经实现导入器**。学校、课程、教师、学生编号均为虚构；邮箱使用不可投递的 `example.invalid`。公开仓库中不要替换为真实名册。

完整字段、关系与处理规则见[导入规范](../../docs/import-spec.md)。编码为 UTF-8，首行为英文表头，多值用 `|`，日期用 `YYYY-MM-DD`；编号始终按文本处理，保留 `0001`、`000001` 的前导零。Excel 打开 CSV 可能丢前导零，建议通过“从文本/CSV 导入”将编号列指定为文本。

## 文件与导入顺序

| 顺序 | 文件 | 内容 |
| --- | --- | --- |
| 1 | [terms.csv](terms.csv) | 学期、首周周一、时区与学时分钟数 |
| 2 | [periods.csv](periods.csv) | 学期节次与午前/午后时段组 |
| 3 | [teachers.csv](teachers.csv) | 教师名册；不创建密码、不自动激活账号 |
| 4 | [classrooms.csv](classrooms.csv) | 校区/楼宇/教室、容量与设备 |
| 5 | [offerings.csv](offerings.csv) | 课程目录、教学班、开课与教师范围 |
| 6 | [enrollments.csv](enrollments.csv) | 学生编号、实际选课及生效区间 |
| 7 | [calendar_exceptions.csv](calendar_exceptions.csv) | 停课及替换教学日 |
| 8 | [rules.csv](rules.csv) | 规则、教学周与实际授课教师 |
| 9 | [sessions.csv](sessions.csv) | 显式课次、历史完成量；匹配规则课次，不额外重复生成 |
| 10 | [room_blocks.csv](room_blocks.csv) | 考试/维修等非课程占用 |
| 11 | [resource_unavailability.csv](resource_unavailability.csv) | 教师会议/学生考试等人员不可用 |
| 12 | [coverage.csv](coverage.csv) | 各类数据的覆盖范围和来源更新时间 |

推荐上传为同一批次的文件集合，全部预览后一次提交；逐文件导入时遵循上表依赖顺序。XLSX 使用同名工作表及相同字段，本次只提供 CSV，没有生成 XLSX。

批次参数（在管理后台选择，不需要每行重复）：`school_code=DEMO-SCHOOL`、`source_system=demo_csv_v1`、`mode=merge`。它们只是虚构演示环境的标识。

## 样例能验证什么

- 学期为 2026-09-07 至 2027-01-24，首周周一是 2026-09-07；2026-10-26 是第 8 教学周。
- 刑事侦查示例课的单周由 `0001` 授课、双周由 `0002` 授课，课程共享范围包含两人。
- 学生 `000001` 同时选两门课；把 2026-10-26（第 8 周）1–2 节移到同日 3–4 节时，应发现学生冲突；该日两课教师不同，不应误报教师冲突。奇数周这两门课均由 `0001` 授课，则还存在教师冲突。不能只按班名判断。
- 2026-10-05 停课，2026-10-10 执行 10-05 的教学安排；规则课次保留原教学日期，不能多算一次。
- `S-CRIME-W05`、`S-CRIME-W07` 是明确记录的两次历史完成课，各 2 学时；重复导入后刑事侦查课程仍只完成 4 学时。
- `S-DATA-W07` 在历史日期仍是 `scheduled`，不能自动增加已完成学时。
- 10-28 的教室维修、教师会议、学生考试分别用于检查非课程占用。
- `coverage.csv` 中 complete 只声明**这个虚构演示学校数据集**完整，不能当成任何真实学校的数据证明。

规则与校历展开后应有 40 个具体课次：刑事侦查 20 次、数据分析 20 次。sessions.csv 三行均匹配已有规则课次，不新增课次；其中 2 次 completed、38 次 scheduled，合计实际完成 4.0 学时。样例中没有备注、交接或教学计划数据；这些通过 App 操作创建。

## 使用时的关键约定

默认 `merge`：文件里没有的记录保持原样。相同来源稳定编号更新原对象；调课只改日期/时间，不能另换课次编号。课程/规则/课次如已存在教学记录、完成量或已批准调课，导入预览需提示人工决定，不能静默覆盖。

所有 `effective_until` / `until_date` 都是**不含当天**的上界；学期 `end_date` 是含当天。样例选课和覆盖截止 `2027-01-25`，因此覆盖至学期最后一天 `2027-01-24`。

可空字段保留空单元格；不要填写 `null`、`无` 或 `-`。不要在 CSV 正文添加注释行。带逗号或换行的文字按标准 CSV 使用双引号包围。
