# 开发任务与验收清单

> 所有任务当前均为待实施。以下是可直接转为 GitHub Issue 的任务规格，不是完成报告。优先级 P0 指完整 v1 必须交付，P1 指试点后的增强。阶段、时长基线见[实现方案](implementation-plan.md)。

## M0：先验证复用与外部链路（3–5 个工作日）

### B00 工具链、仓库与工程骨架｜P0

- 创建 Flutter Android/iOS 工程、Django/DRF 工程与 PostgreSQL 开发环境。
- 确定自定义 User 模型并生成首个迁移；锁定 Flutter、Python 3.12、Django 5.2 补丁和数据库版本。
- 提交依赖锁文件、最小环境说明、CI；完成 Android debug/release 和 Mac iOS 构建。
- 验收：另一台开发环境按 README 启动 API 和 App；健康检查正常；当前模拟数据明显标注。

### B01 认证组件与邮件回跳验证｜P0｜依赖 B00

- 复用 dj-rest-auth/allauth/SimpleJWT，验证注册、验证邮件、登录、refresh、退出、重置/修改密码。
- App 深链打开验证/重置页；邮件在另一设备打开时也能复制链接在 App 继续。
- 明确改密/重置后撤销旧 refresh，服务端 JWT blacklist 配置和测试记录在案。
- 验收：不新写 JWT/密码验证算法，真邮箱和 Android/iOS App 至少贯通一次；双端字段合同冻结。

### B02 课表组件与关键输入验证｜P0｜依赖 B00

- 对比 YIClass 可提取界面与 calendar_view；一天内验证节次、午休、并发课程、周末、大字号。
- 用一份授权匿名样本跑 CSV/XLSX 解析与教学周展开；记录学校缺失字段。
- 验收：选型记录给出采用组件、适配范围与放弃理由；只能局部自写缺失布局，不重写基础框架。

### B03 推送最小链路与设备矩阵｜P0｜依赖 B00

- 选用个推官方插件，区分开源插件、原生 SDK 与商用服务；提交厂商/APNs 账号申请。
- Android 一台和 iOS 一台验证服务端→系统通知→点击回 App；列出试点机型与通道开通条件。
- 验收：明确前台/后台/进程关闭哪些已实测，供应商受理不等于设备送达；未开通机型作为发布阻塞项跟踪。

## M1：账号、正式数据与查课（10–12 个工作日）

### B10 账号与个人设置｜P0｜依赖 B01

- 完成注册/邮箱验证/待确认/可用/停用所有状态；名册邮箱和工号双匹配自动关联，否则教务确认。
- 完成改密、找回、登录态恢复、退出、注销入口、资料头像、联系方式和字号/提醒设置。
- 验收：新教师从注册走到本人课表，pending 不会被卡在无说明页面；账号切换不混缓存；联系方式默认不公开。

### B11 教务数据模型与 Admin｜P0｜依赖 B00、B02

- 实现学期、节次、教师、教室、教学班开课、任课、选课有效期、重复规则、具体课次、校历例外、不可用时段与覆盖范围。
- 自定义 Admin 必要列表/筛选/操作，所有正式课表变更进入 scheduling service。
- 验收：用示例数据建立一学期；稳定课次 ID 和唯一约束成立；可在 Admin 修正一门课且 App 能看到更新。

### B12 导入预览、差异与确认｜P0｜依赖 B11

- 固定 CSV/XLSX 模板、列映射、staging、错误行报告、增量/指定范围快照模式。
- 规则和具体课次明确映射，支持全新导入和期中显式历史完成课次；已调课/已完成/有记录的覆盖列为需确认。
- 验收：重复导入不重复、增量缺行不误删、错误批次不部分生效；报告有定位与修正建议。

### B13 今日/周/教学班课表｜P0｜依赖 B10、B11、B12

- 四标签导航、今日卡片、周视图、教学周跳转、课程详情、快捷菜单、铃铛入口。
- 正确显示单双周、补星期、停课、跨午休既有课程与重叠排课；提供未导入/无课/网络失败状态。
- 验收：图片中主要移动交互能用真实 API 操作，首页两次点击可打开备注页；系统大字号能读完整详情。

### B14 缓存、变更日志与消息骨架｜P0｜依赖 B11、B13

- Repository + Drift、bootstrap/增量变更、版本和 tombstone、前台恢复/下拉同步。
- 任课范围变化时清相关缓存并重新 bootstrap，保留本人待提交草稿；消息/投递表与事件去重。
- 验收：无网络仍可看已缓存课表并显示更新时间；调离教学班后本地不继续显示原共享数据。

## M2：教学记录、交接与计划（10–12 个工作日）

### B20 备注、历史与离线草稿｜P0｜依赖 B13、B14

- 三段备注、私有草稿、显式发布、本人修改版本、上次已完成课次的共享记录。
- 本地随写随存、client_mutation_id 去重、base_version 冲突保留两份文本。
- 验收：断网写后关闭 App 内容不丢；恢复只提交一次；同名不同开课不串记录；补录旧课不替换最近授课。

### B21 多教师交接闭环｜P0｜依赖 B20

- 预填交接、选择授课教师、发送、未读/已读/待确认、显式确认、撤回与补充。
- 已发送正文为快照；换任课人/调课后提示核对待确认交接接收人。
- 验收：两教师设备互相协作，已读不变确认，确认后保留时间；发件人收到确认消息。

### B22 教学计划与完成学时｜P0｜依赖 B20、B11

- 负责人维护章节、目标学时、计划日期/课次；教师确认完成课次并分配专题学时。
- 汇总已完成/剩余/超出学时、未来课次和历史待确认数；实现更正原因与取消重算。
- 验收：两位教师同课次只计一次；保存备注不增加学时；专题分配不超实际；没建计划不误判延期。

### B23 进度提醒｜P0｜依赖 B22、B14

- 按计划截止与实际差额生成每日摘要，同一 CourseOffering 当天不重复；同班不同课程分别提醒，补齐后更新状态。
- 验收：阈值与日期边界正确；消息可跳到计划；计划调整不静默覆盖历史基准。

## M3：调课与教室协查（10–12 个工作日）

### B30 候选时间与冲突解释｜P0｜依赖 B11、B13

- 按目标日期实际选课、授课教师、教室及不可用时段检查；容量、必需设备和校历约束。
- 统一 `available/conflict/unverified`，返回原因、数据覆盖与版本；实现固定排序。
- 验收：跨班选修学生冲突能检出；缺名单只能待核验；午休禁调；同样输入结果稳定；性能按约定基准测量。

### B31 申请、登记审批与正式生效｜P0｜依赖 B30、B14

- 申请/撤回/记录，Admin 登记学校结果；统一事务内锁定与再检查，写变更快照和通知。
- 对学校强制安排有单独明确入口、依据与风险标识；普通教师不能绕过冲突。
- 验收：两个申请争同房同时间只可一条正常确认；申请不改变课表，批准后各视图一致，备注/进度 ID 不变。

### B32 教室时间线与联系｜P0｜依赖 B13、B10

- 教室检索、日期、前后课程、非课程占用、变更记录、本人联系方式可见范围。
- 验收：调出/取消不显示成有效占用；电话/微信按范围返回，拨号/复制真机可用；固定说明排课不等于到场。

### B33 失物协查请求、回复、结案｜P0｜依赖 B32、B14

- 从日期区间列出相关授课教师，发起人勾选接收人；输入物品说明，对方回复，发起人结案。
- 文本留言即可，不加实时聊天/在线状态/通用工单。
- 验收：无公开联系方式也可联系相关教师；指定接收人能在消息中心进入，回复有通知，关闭后状态一致。

## M4：通知、联调与试点发布（10–15 个工作日）

### B40 通知中心、本地提醒和远程投递｜P0｜依赖 B03、B14、B21、B31、B33

- 未来 7 天/最多 50 条上课提醒、变更撤销旧提醒、业务通知去重、推送点击定位。
- 定时投递命令、有限重试、供应商受理/回执/已读分开；账号退出解绑设备与取消本地通知。
- 验收：Android/iOS 真机覆盖前台、锁屏、进程关闭、拒绝通知权限；目标试点机型通道明确可用。

### B41 端到端验收与可访问性｜P0｜依赖全部功能

- 跑领域文档验收场景、匿名规模数据性能测量、Android/iOS 字号/长课程名/长文本/跨月视图。
- 用真实授权学校样本核对教学周、选课人数、课时、教室历史，记录数据覆盖缺口。
- 验收：没有阻断四核心的占位按钮或模拟成功；缺口能在产品里说明；试点缺陷清单收敛。

### B42 部署、构建和交接｜P0｜依赖 B41

- 提供锁定镜像、Compose/配置示例、数据库迁移、备份恢复、健康检查、正式邮件/推送配置说明。
- Android Release 安装包、iOS TestFlight、使用说明、教务导入说明和已知限制。
- 验收：新主机可部署、备份实际恢复一次、5–10 位教师至少试用一教学周；商店公开发布按后续明确动作执行。

## Issue 统一写法

每个 Issue 写清：具体教师/教务场景、输入/输出、依赖、验收例子、相关文档。关闭前附实际检查结果；需要学校/推送/邮件参数时列为外部依赖，其他不依赖的工作继续推进。
