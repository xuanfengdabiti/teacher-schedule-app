# 警校研究生教师课表 APP｜开发概要

> 面向研究生任课教师，以当天课表为首页，提供轻量、柔和、清晰的教学辅助体验。本文为初步开发范围，不涉及详细技术设计。

## 设计预览

![移动端及网页版 UI 设计预览](ui-preview.png)

## 产品形态

- **移动 APP（优先）**：进入即显示当天课表，大字号课程、时间、教室；可切换周课表。
- **网页版（配套）**：适合大屏查看周课表、批量管理课程及教学安排。
- **交互方式**：点击或长按课程卡片进入快捷操作；点击教室名称查看历史使用记录。

## 核心开发内容

### 1. 课表与智能调课
- 今日课表、周课表、教学周切换；查看教学班课表。
- 查询教师、实际选课学生和教室的时间冲突，推荐候选调课时段。
- 支持调课记录；正式调整以学校审批结果为准。

### 2. 教学备注与多教师交接
- 每节课记录已讲内容、未完成内容、下次计划。
- 下一次同课程授课时自动显示最近教学记录。
- 多教师共享课程进度，支持交接信息及必要的确认。

### 3. 教学计划与课时进度
- 展示总学时、已完成学时、剩余课次。
- 管理章节/专题计划，查看实际进度和延迟提醒。

### 4. 教室历史使用与失物协查
- 按教室和日期查看排定的前后课程及授课教师。
- 教师姓名旁提供“联系”入口，点击查看教师自愿填写的电话或微信号。
- 联系方式可自主编辑、设置可见范围；支持复制或站内联系。
- 课表记录仅用于协查，不代表实际到场或物品去向。

## 其他基础功能
- 校内教师登录与课程权限控制。
- 课表数据导入、更新及异常提示。
- 消息提醒、个人设置、联系方式维护。
- 适配手机与桌面屏幕，统一视觉风格。

## 开发顺序建议

1. **第一阶段**：教师登录、今日/周课表、班级课表、教学备注、教室使用记录及联系方式。
2. **第二阶段**：多教师交接、教学计划、课时统计、调课冲突查询。
3. **第三阶段**：教务系统对接、审批联动、通知与失物协查闭环。

## 关键前提

调课准确性依赖学校授权的教师、选课学生、教室及临时变更数据。教师联系方式和教室历史记录应实行身份验证、最小权限和必要的访问审计。
