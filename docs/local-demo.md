# 本地演示启动包

用于本机演示的虚构环境：Django API + PostgreSQL，示例数据为 **37 门课程、13 位教师、30 间教室、878 名虚构学生、1440 个课次**，含 13 个教师账号、1 个教务账号和少量备注/计划/交接/失物询问样例。校区和楼宇名称由用户指定，人员、房号、课程及安排为合成示例。

## 一键启动

先启动 Docker Desktop，并安装 PowerShell 7（`pwsh`）。在仓库根目录执行：

```powershell
pwsh scripts/start-demo.ps1
```

脚本会：

1. 用 `infra/deploy/.env.demo` 的虚构参数构建并启动独立 Compose 项目 `teacher-schedule-demo`。
2. 轮询健康检查端点 `http://127.0.0.1:18000/api/v1/health/`，直到返回 200。
3. 把 `templates/import/*.csv` 和基础、扩充、三教师团队、团队整周课程种子脚本复制进 api 容器。
4. 先导入 12 个 CSV 的基础课表，再执行扩充脚本补齐整学期课次、应用研究生节次；执行 `scripts/seed_demo_team.py` 添加李、张、王三位老师及轮讲课程，再执行 `scripts/seed_demo_team_extra.py` 给每人补充 4 门课程。
5. 四步都可重复执行：已有 code 保留，不重复导入，不覆盖演示者已保存的备注、计划、交接、失物询问或调课。

停止：

```powershell
docker compose -p teacher-schedule-demo --env-file infra/deploy/.env.demo -f infra/deploy/compose.yaml down
```

如需清空演示数据重新开始（会删除本项目自己的数据卷，不影响其他项目）：

```powershell
docker compose -p teacher-schedule-demo --env-file infra/deploy/.env.demo -f infra/deploy/compose.yaml down -v
```

## 四核心演示路径

演示数据学期为 `2026-autumn`。当前日期不是演示日时，请选 **2026-10-26 所在周** 或 **2026-11-02 所在周**。建议先用李老师：2026-10-27 有 4 次课，分别从 08:10、10:00、14:00、15:40 开始；前三门轮讲课程在 10/29 由王老师接课，下一周周四由张老师接课。三位老师每人另有每周 8 次补充课，周一到周五每天都有安排。

1. **课表与调课**：李老师查看 2026-10-26 所在周，可在“按日列表 / 整周总览”之间切换，点课程进入详情；整周总览按 7 天、8 节显示，连上两节的课占满两节高度。今日页使用课程卡片。对课次可查询候选并发起调课，教务在 Admin 登记审批结果。课程详情和调课页显示课程名称、时间、地点，不显示课次 UUID、开课班号等内部编号。
2. **备注与进度交接**：老师可以只写一两句话，三栏不必都填。保存后，下一次同课程的“今天 / 按日列表”卡片默认显示最多两行“备注”；优先显示下次课计划，其次未完成内容、已讲内容，整周格子也有简短标记。“保存草稿”仅供自己查看；点“共享备注”后同课老师也能看到，不用先登记完成学时。李老师 10/27 的证据法专题研讨已配置来自 10/20 的短备注“下次讲证据链审查，带一个案例。”。点“进度交接”勾选张老师或王老师；“交接给下次课”旁直接显示日期、节次和接课老师。王老师可在“功能 → 进度交接 → 收到的”查看并确认，旧样例继续保留。
3. **教学计划与学时**：教师甲打开刑侦课程的教学计划，能看到两个 20.0 学时的虚构专题（截止 2026-11-02、2026-12-21）；从课次详情点“登记学时”，可确认/更正完成学时并分配专题。种子不重算业务学时。
4. **教室、空教室与失物消息**：从“功能 → 空教室查询”选择日期、起止时间，可搜索地点、最小容量，或用“更多筛选”指定校区、楼宇；点结果打开该日“教室记录”。统一入口“功能 → 教室与失物”内有“教室记录 / 失物消息”两个页签。从某教室记录发起失物询问会保留所选日期，发送成功返回“失物消息 → 我发起的”并刷新。旧样例中教师甲发起的蓝色笔记本询问、教师乙的回复和结案操作继续可用。

空教室查询按现有课表与临时占用记录筛选，有课、维修或其他占用的教室会被排除；没有完整数据的结果显示“需确认”。接口与规则见 [空教室查询](classroom-availability.md)。演示环境可能保留此前验收的交接确认、失物询问结案等操作，可按上方清空说明重新初始化。
