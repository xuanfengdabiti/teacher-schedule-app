# 本地演示启动包

用于本机演示的虚构环境：Django API + PostgreSQL，示例数据为 **22 门课程、10 位教师、30 间教室、503 名虚构学生、840 个课次**，含 10 个教师账号、1 个教务账号和少量备注/计划/交接/协查样例。校区和楼宇名称由用户指定，人员、房号、课程及安排为合成示例。

## 一键启动

先启动 Docker Desktop，并安装 PowerShell 7（`pwsh`）。在仓库根目录执行：

```powershell
pwsh scripts/start-demo.ps1
```

脚本会：

1. 用 `infra/deploy/.env.demo` 的虚构参数构建并启动独立 Compose 项目 `teacher-schedule-demo`。
2. 轮询健康检查端点 `http://127.0.0.1:18000/api/v1/health/`，直到返回 200。
3. 把 `templates/import/*.csv`、`scripts/seed_demo.py` 和 `scripts/seed_demo_extra.py` 复制进 api 容器。
4. 先导入 12 个 CSV 的基础课表，再执行扩充脚本：补齐课程、教师、教室和整学期课次，并应用研究生节次时间表。
5. 两步都可重复执行：已有 code 保留，不重复导入，不覆盖演示者已保存的备注、计划、交接、协查或调课。

停止：

```powershell
docker compose -p teacher-schedule-demo --env-file infra/deploy/.env.demo -f infra/deploy/compose.yaml down
```

如需清空演示数据重新开始（会删除本项目自己的数据卷，不影响其他项目）：

```powershell
docker compose -p teacher-schedule-demo --env-file infra/deploy/.env.demo -f infra/deploy/compose.yaml down -v
```

## 四核心演示路径

演示数据学期为 `2026-autumn`。当前日期不是演示日时，请选 **2026-10-26 所在周** 或 **2026-11-02 所在周**。扩充后周内每天都有课；默认课表中教师甲周二有 3 次课（08:10、09:00、14:00 起），可直接演示。

1. **课表与调课**：教师甲查看 2026-10-26 所在周，可看到周二 3 次课以及周一、周三至周五的示例课程；教师乙同样周一至周五有课。可对课次发起调课，教务在 Admin 登记审批结果。
2. **备注与交接**：教师甲打开 2026-10-19 已完成的刑侦课次，能看到种子写入并已发布的三段中文备注，可继续编辑并发布。交接列表里已有甲发给乙的虚构交接：乙可查看、确认，甲可撤回。
3. **教学计划与学时**：教师甲打开刑侦 offering 的教学计划，能看到两个 20.0 学时的虚构专题（截止 2026-11-02、2026-12-21）；从课次详情进入完成登记，可确认/更正完成学时并分配专题。种子不重算业务学时。
4. **教室、空教室与协查**：从“功能 → 空教室查询”选择日期、起止时间，可搜索校区/楼宇/教室编号及最小容量；“更多筛选”可精确指定校区、楼宇。扩充后共 30 间教室，请以实际查询结果为准（例如查 2026-11-02 08:10–09:40，会列出该时段无课的教室，并按覆盖显示“可用/待核验”）。点结果打开该日教室历史；原“教室查询”入口改名“教室历史”。教师甲在协查列表能看到 A301、2026-10-26 08:00–09:40 的“蓝色笔记本”协查（该协查是扩充前的样例，时间按当时课表）；教师乙收到后可回复，教师甲可结案。

空教室查询按现有课表与临时占用记录筛选，有课、维修或其他占用的教室会被排除；没有完整数据的结果显示“待核验”。接口与规则见 [空教室查询](classroom-availability.md)。演示环境可能保留此前验收的交接确认、协查结案等操作，可按上方清空说明重新初始化。
