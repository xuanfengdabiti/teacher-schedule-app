# 个人资料、密码与字号

本地演示的“我的”页提供个人资料编辑、修改密码和字号设置。沿用已有账号、接口与 Flutter 控件，不引入新的认证系统、通知插件或本地数据库。

## 个人资料

从“我的”进入“编辑资料”，可修改显示名、院系、电话、微信以及电话和微信各自的可见范围。工号、正式姓名和邮箱用于确认教师身份，只读展示。取消编辑不会提交，保存成功后“我的”页显示最新资料。

联系方式可选择“仅本人 / 同课程教师 / 全校教师”，打开表单时沿用已保存的选择；不会因编辑其他字段而恢复成默认值。教室记录中的联系方式继续遵循现有可见范围规则。

## 修改密码

从“我的”进入“修改密码”，填写当前密码、新密码和确认密码。不一致时直接提示；请求失败时保留输入。修改成功后返回登录页，使用新密码重新登录。

李、张、王快捷填入使用文档中的固定演示密码。验收改密使用教师甲，并在结束后恢复原密码，避免破坏三位老师的快捷演示。

## 字号

“字号设置”提供“跟随系统 / 大 / 更大”。保存后立即应用到 App 页面，重新登录时读取当前账号的选择。退出和换账号不会沿用上一位老师的字号；偏好读取失败不阻塞正常查课。

## 复用与边界

- 资料使用既有 `GET/PATCH /api/v1/me/`；修改密码使用 `POST /api/v1/auth/password/change/`，复用 dj-rest-auth/allauth 的密码流程。
- 字号使用既有 `GET/PATCH /api/v1/me/preferences/`，只提交 `font_size`，不改提醒、推送等未提供手机操作入口的设置。
- 界面复用 Flutter Material、Riverpod、Dio 与 SharedPreferences；许可证和锁定版本见 [THIRD_PARTY.md](../THIRD_PARTY.md)。不复制新的第三方源码或引入依赖。
- 这里的字号设置不代表已实现系统课程提醒、真实远程推送或完整冷启动离线课表。实际构建与操作结果见[本地演示验收](local-demo-acceptance.md)。
